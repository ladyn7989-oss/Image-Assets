# Date With Destiny — Ren'Py Edition

Visual novel dating sim with belly pet mechanics, ported from HTML PWA to Ren'Py.

## Building the APK (No PC Required!)

1. Push changes to the `main` branch
2. Create a git tag: `git tag v1.0 && git push origin v1.0`
3. GitHub Actions automatically builds the APK
4. Download from the Releases page on your phone

## Manual Build (if you have a PC)

1. Download Ren'Py SDK 8.2.3 from https://www.renpy.org/latest.html
2. Open this project folder in Ren'Py
3. Click "Build Android Packages"
4. Install the APK on your phone

## Characters

22 characters including Beerus, Champa, Husk, Vox, Vegeta, Anubis, Vincent,
Fomo, Wolf, Glacia, Riko, Aether, Luna, Nyx, Zero, Luce, Louis, Legoshi,
Riz, Bill, Gohin, and Solene.

## Features

- City Map navigation with energy system
- Character story routes (7 scenes each)
- Belly Pet Mode (squirm, massage, talk, closeness, drain)
- AI Chat system (15 categories, keyword-based)
- Riko's Collection system (10 targets)
- Cheat Mode
- 20 Achievements
- Gift System & Shop
- Endless Mode
- Day/Night cycle
- Random encounters
- Music (CC-licensed from Internet Archive)
